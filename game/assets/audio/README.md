# Trilha sonora do ECO NAVE 2.0

`eco_nave_theme.ogg` é uma trilha chiptune instrumental original, sintetizada para este projeto com osciladores e ruído gerado por código. Não utiliza gravações nem samples de terceiros. `eco_nave_theme.wav` é uma cópia PCM de fallback.

A faixa foi criada como alternativa porque o download da música indicada no OpenGameArt não pôde ser concluído no ambiente de preparação. Portanto, ela **não** é a faixa de congusbongus.

Para substituir a música, coloque um arquivo OGG compatível nesta pasta com o nome `eco_nave_theme.ogg`. O jogo também pode ser apontado para outro caminho em `eco_nave/audio_manager.py`.
